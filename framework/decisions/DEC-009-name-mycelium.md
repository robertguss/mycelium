# DEC-009 — The framework is named Mycelium

- **Status:** Accepted
- **Date:** 2026-08-14
- **Owner:** Robert Guss
- **Supersedes:** None
- **Related recommendations:** None
- **Related evidence:** None

## Context

"Artifact-driven-research-program" describes v1's scope. The evolved
framework is a thinking framework with an idea lifecycle wrapped around the
research spine, and the old name no longer fits. Candidates floated: Simmer,
Mycelium, Forethought.

## Decision

The framework is named **Mycelium**. In-repo naming (methodology name,
README identity) adopts it during PHASE-01. The GitHub repository rename is
deferred and cheap (GitHub redirects old URLs); timing is OQ-005.

## Rationale

Mycelium is the underground network that does the real work long before
anything fruits above ground, which is what simmering ideas do. It also
evokes many connected ideas sharing one substrate (the master's conventions).
Robert's verdict: "that's a banger."

## Consequences

Docs, manifest naming (OQ-002), and eventual repo rename reference one name.
The name collides with unrelated products in other spaces (e.g., a Bitcoin
wallet), which is acceptable for a personal framework and worth rechecking
only if Mycelium is ever published broadly.

## Alternatives Considered

Simmer (names one state, not the whole), Forethought (accurate, less alive),
keeping the v1 name (scope-inaccurate).

## Risks

None material at personal scale.

## Revisit Triggers

Broad publication or productization of the framework.

## Approval

Approved by Robert Guss, 2026-08-14 ("I love Mycelium as a name. that's a
banger!").
