# Decision Records

Formal `DEC-###` records for foundational, disputed, expensive-to-reverse,
security-sensitive, or authority-superseding decisions.

- Template: `program/templates/decision-record.md`
- Contract: `program/contracts/decision-records.md`
- Filename pattern: `DEC-###-short-title.md`

Routine Blueprint/Charter decisions may be approved with the governing artifact
as a whole; they do not all need formal DEC files.

Formal decisions require **explicit human approval**.
