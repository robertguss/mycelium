# Handoffs and Attachment Manifests

For each substantive stage, store:

```text
docs/handoffs/<stage-id>-attachment-manifest.md
```

Templates:

- `program/templates/attachment-manifest.md`
- `program/templates/launch-message.md`
- `program/templates/stage-package.md`

Handoff Digests live inside research reports; they never silently replace full
source artifacts.
