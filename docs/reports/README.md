# Focused Research Reports

Place accepted (and in-progress) focused research reports here:

```text
docs/reports/01-<focus>-research-report.md
```

Tracks are **not** pre-created. After Blueprint acceptance, create reports via
just-in-time prompts using `program/templates/focused-research-prompt.md` and
the report contract in `program/contracts/focused-research-report.md`.

A placeholder filename does **not** mean the stage is complete.
