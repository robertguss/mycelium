# Council pack

Presence-is-registration: this directory under `program/packs/council/`
enables the perspective-ladder pack. Delete it on an instance to disable.
No registry file.

No portable council CLI. Surface is `mycelium new commissioning`,
`mycelium new model-report`, `mycelium new reconciliation`, `mycelium check`,
and the `council` / `second-opinion` skills. Suggest only when a
replication trigger fires. State cost class first.
