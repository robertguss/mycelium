# Spark

First session inside a new instance.

## Steps

1. Read `index.md` and `log.md` (not the whole tree).
2. `mycelium state exploring`
3. `mycelium new decision "…"` (first thought)
4. `mycelium check`

## Do not

- Invent a hub.
- `git commit` unless the human asks.
