# Wake

On re-entry to a simmering idea.

## Steps

1. Run `mycelium wake`
2. Read `briefs/LATEST.md`
3. Work from the brief. Follow `thinking`. Run `mycelium check` before
   handing back.

Done: brief exists, `state` is `exploring`, `check` is green.

Do not start from `log.md` before the brief.
Do not `git commit` unless the human asks.
