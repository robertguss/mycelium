# Generic Adaptation Beyond Software

The governance spine remains valid outside software. Adapt focused research
tracks and final specification vocabulary.

Examples:

- **Legal:** legal theory, jurisdictional analysis, procedural strategy,
  evidentiary requirements
- **Market:** users, competitors, pricing, distribution, unit economics
- **Scientific:** hypotheses, methods, datasets, reproducibility, statistics
- **Theological:** primary texts, historical interpretation, language,
  doctrinal frameworks, competing schools
- **Operational:** workflow, controls, staffing, failure modes, metrics,
  governance

Never pretend that engineering experiments replace domain-qualified professional
judgment where law, medicine, safety, or regulated practice requires it.
